# Notes — 작업 일지

날짜별 작업 기록. **무엇을 왜 했고, 무엇에 걸려 넘어졌는지**를 그때의 맥락 그대로 남긴다.

`docs/`가 정제된 결론이라면 여기는 **거기 도달한 과정**이다. 오진과 헛다리도 남긴다 —
같은 함정에 다시 빠지지 않으려면 결론보다 과정이 쓸모 있을 때가 많다.

## 쓸 때 지킬 것

**공개 저장소다.** 호스트명·내부 IP·포트·경로는 혼자 보려고 일부러 적지만,
아래는 예외 없이 제외한다.

- 비밀번호·API 토큰·SSH 키·`restic.key` 같은 **자격증명 값 자체**
- `.env` 파일 내용, DB 접속 문자열
- 인증 쿠키, 세션 값

**"어디에 있다"까지만 쓴다.** 값은 쓰지 않는다.

```
✅  Cloudflare 토큰은 `~/.env` 의 CF_ALL
❌  CF_ALL=abc123...
```

터미널에 한 번 찍힌 값(초기화한 비밀번호 등)도 마찬가지다. 기록에 옮기지 않는다.
필요하면 **어떻게 다시 얻는지**를 적어두는 편이 낫다 — 값은 바뀌지만 경로는 남는다.

## 미해결 (누적)

작업 중 발견했지만 아직 손대지 못한 것들. 처리하면 해당 일지에 체크하고 여기서 뺀다.

### 우선순위 높음

- [ ] **`restic.key` 별도 보관** — 살아있는 restic repo 3개가 이 64바이트 파일 하나에 의존.
      잃으면 전부 복구 불능. 2026-07에 `archives/orico` 185G를 암호 분실로 실제 폐기했다
- [ ] **msg10p 자체 백업 부재** — 모든 백업의 종착지인데 자기 사본이 없다.
      미러라 디스크 1장 고장은 버티지만 실수 삭제·풀 손상·화재엔 무방비.
      bakpool 재구성에 8~10T CMR 필요

### 검토 중

- [ ] **NFSv4 전환** — 서버는 `+3 +4 +4.1 +4.2` 이미 활성, 클라이언트만 바꾸면 됨.
      메타데이터 집약 작업(Jellyfin 라이브러리 스캔 등)에서 이득 예상.
      순서: prodesk `ds920p` 시험 → 나머지 → 맥은 마지막(`nfs-watchdog` 검증 필요)
- [ ] **오프사이트 범위** — R2에 있는 건 `~/work`·`~/Downloads`·사진뿐.
      시놀로지 덤프 4T, 외장하드 사본 2.4T는 집 안에만 존재
- [ ] **`zpool/photo` vs `zpool/photos`** — 이름이 `s` 하나 차이인 280G대 데이터셋 둘.
      중복 의심되나 파일 비교 미실시

### 소소한 것

- [ ] **`local-backup-notify.sh`** (msg10p) — 삭제한 `zfs-replicate-notify.sh`를 참조 중일 수 있음
- [ ] **`zfs-scrub`와 `db-backup` 시간 겹침** — 매월 1일 03:00. 월 1회라 치명적이진 않음

      높은 `USEDSNAP`이 정상. 비율만으로는 사고와 구분이 안 된다. 데이터셋별 예외 검토 중

- [ ] **Pinchflat 유튜브 봇 차단** — 일부 영상만 실패. 쿠키 방식은 브라우저 전체 쿠키가
